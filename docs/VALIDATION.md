# 验证记录

核实环境：Windows 内核 10.0.17763，当前构建进程不是管理员。检查对象为本地构建的 x86/x64 原生程序；测试证书与账号均为临时合成数据。

## 已执行

两种架构各通过：

- 52 项原生核心/凭据检查：HTTPS 地址、路由和掩码输入边界、完整 SHA-256 固定公钥、Unicode、诊断脱敏、启动前取消，以及 Windows Credential Manager 的保存、读取、信任/地址隔离和删除。
- 10 项真实 TLS 回环集成场景：固定公钥成功登录、不可信证书、错误指纹、错误密码不重试、额外认证不泄露密码、跨来源跳转、私有 CA 正确名称、私有 CA 名称错误、CA 模式跨来源跳转、认证中取消。
- 9 项导入场景：CA 配置文件、指纹配置文件、拒绝混合信任模式、拒绝 HTTP、拒绝缺少信任材料、拒绝缩短指纹、拒绝私钥、直接 PEM CA、直接 DER CA。
- PE 子系统版本 6.1、只导入系统 DLL、没有 Qt/VC 可再发行运行库/UCRT DLL、没有检查表中已知的 Win7 之后才存在的导入函数。
- 中文/英文原生窗口渲染及空账号密码操作的冒烟检查。截图来自本程序自身窗口，不是网页示意图。

Wintun ZIP SHA-256 与官网公布值一致，x86/amd64 DLL 的 Windows Authenticode 签名检查为有效，签名人为 WireGuard LLC。发行过程不修改 Wintun 文件。

本地详细结果生成在 `test-results`。原生程序的运行库被静态合并；动态加载的官方 Wintun 是单独附带的驱动组件，不应被遗漏在“仅系统 DLL”的表述之外。

## 服务端管理页

已通过 34 项 Lua 5.1 回归：账号增改删、停用和恢复、旧会话失效、密码哈希不回显、并发修改检测、失败回滚、配置校验、原设置保留与公开 CA 导出。UCI/nixio/occtl 边界使用模拟接口，尚不能替代路由器上真实的 LuCI 与 ocserv 联调。

手动 GitHub Actions 会重新执行这些回归，并分别构建客户端和两种服务端包。客户端 Linux 编译产物通过 PE 审计；测试工具随 artifact 提供，便于在 Windows 实际运行。
