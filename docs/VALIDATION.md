# 0.4.0 验证记录

验证日期：2026-09-16。Windows 环境为 10.0.17763，当前构建进程未提权。测试使用临时合成账号、证书和独立目录，不读取真实 VPN 密码，也没有修改用户 N1。

## Windows 客户端

x86 与 x64 分别通过：

| 检查 | 结果 |
|---|---|
| 原生核心与凭据 | 68 项：地址、路由、完整指纹、Unicode、凭据保存/删除及服务器信任隔离 |
| 真实 TLS/登录 | 19 项：首次确认、取消、更换公钥、跨进程记忆、CA/名称校验、错误密码及跨来源跳转 |
| 配置导入与导出 | 19 项：地址、CA、指纹、连接选项往返；更换服务器后不导出旧信任；拒绝私钥和无效选项 |
| 原生窗口 | 中英文主窗口、可编辑地址、空凭据提示、连接状态及首次/变更证书弹窗 |
| PE 导入审计 | 子系统 6.1，仅系统 DLL，无 Qt/UCRT/VC 运行库依赖及检查表中已知的 Win7 后新增导入 |

取消或拒绝证书确认时，回环服务收到的密码提交次数为 0。窗口截图由实际 EXE 生成。官方 Wintun 作为独立驱动 DLL 随包附带，打包不修改其内容；它不属于“仅系统 DLL”这一静态导入表结论。

## 服务端与管理页

| 检查 | 结果与范围 |
|---|---|
| Lua 5.1 管理逻辑 | 36 项，覆盖账号管理、会话撤销、并发、失败回滚、公开配置导出 |
| VPN 专用上网事务 | 23 项，覆盖开关、配置保留、确认超时和开机恢复；UCI/nixio/服务边界为模拟接口 |
| 全新安装与重试 | 12 项，在临时 Linux 文件系统执行实际 install.sh；模拟 APK/UCI/服务，验证备份、恢复及不改 OpenClash/DNS |
| 证书初始化 | 7 项，以真实 GnuTLS certtool/OpenSSL 验证 IP/主机名、用途、私钥权限及保留现有证书 |
| 浏览器交互 | 7 组流程，验证开关完整操作、网络编辑锁、两种配置下载、中英文及移动端；无脚本错误 |
| nftables 隔离 | 18 项，真实 Linux 网络命名空间、路由、连接跟踪、NAT、REDIRECT 与 TPROXY；覆盖 LAN 网关/DNS/代理绕过、VPN 来源伪造、IPv6、管理访问和恢复 |

隔离网络使用 veth 模拟 VPN 接口；登录入口和代理监听为测试服务。它验证规则的实际行为，不代表真实 ocserv 认证或 OpenClash 分流已在 N1 验收。

本地详细结果位于 test-results。服务端仅维护 OpenWrt 25.12.x 的 APK 构建；旧发行版历史记录由 Git 历史和 GitHub Actions 保留。
