# 布利杰VPN 0.5 客户端

## 创建与连接

完整解压对应架构的便携 ZIP，运行“布利杰VPN.exe”。默认中文，通过 **设置 → 语言 → English** 切换。程序使用 Win32/C++17 和官方 OpenConnect 核心，参照 OpenConnect GUI 1.6.2 的配置、认证、日志及托盘交互。

从 **配置 → 新建配置** 输入名称和网关，例如 192.168.19.253:4443，也可以在主窗口直接输入网关。HTTPS 前缀自动补齐，支持端口和用户组路径。下拉列表选择已有配置，**编辑** 修改所选项目。

点击 **连接** 后按需完成 Windows 管理员授权。证书验证完成后，按服务器返回的弹窗填写用户名、密码、分组、验证码或确认通知。连接过程中可取消，连接后可断开。

**VPN 信息** 页显示 IPv4、IPv6、DNS、TLS/DTLS 加密方式和流量。**查看日志** 打开独立窗口，支持复制、选择、清空及自动滚动。密码、令牌和认证 cookie 会从日志中隐藏。

## 高级配置

**新建高级配置** 或编辑已有配置可设置：

- VPN 协议、用户名和认证分组。
- 公共 CA、完整 pin-sha256 指纹、用户证书及私钥；用户证书可从文件或 Windows 证书存储选择。
- HOTP、TOTP、RSA STOKEN 软件令牌。
- 网卡名称、vpnc 脚本、日志级别、重连超时和 DTLS 重试间隔。
- 连接后最小化、记住密码、禁用 UDP、使用系统代理。

默认使用随包的 vpnc-script-win.js 配置网卡、路由和 DNS。自定义脚本由 Windows Script Host 执行，应只选择自己信任的本地脚本；导入、导出不会携带脚本。PKCS#11、TPM 和浏览器 SSO 未编入此便携版。

网络脚本的必要操作失败会终止连接；重连脚本失败也不会报告成功。脚本最多等待 60 秒，超时后结束脚本及其子进程，再执行清理。清空本来不存在的 DNS/WINS 条目不作为连接失败。

## 服务器证书

客户端先验证 TLS 证书，再处理用户名与密码。遇到未知自签证书或名称不匹配时，窗口显示服务器主机/端口、完整公钥指纹和证书详情。核对后点击 **信息准确，记住并连接**；取消时不提交密码、不记住指纹。

指纹保存在所选配置中，绑定规范化的 HTTPS 主机与端口。同一服务器的路径变化不会清除它；公钥变化时显示新旧指纹并要求重新确认。固定指纹不匹配、指定 CA 验证失败、证书过期或尚未生效时拒绝连接。

未指定指纹或 CA 时，使用 Windows 证书链和主机名校验。跨主机或端口跳转需要独立验证，不自动填入原服务器的用户名、密码或软件令牌。

## 密码与便携数据

用户名保存在配置中。**记住密码** 开启时，只有成功认证的密码才用当前 Windows 用户的 DPAPI 加密保存。验证码不作为密码保存，错误的已存密码会重新弹窗。取消“记住密码”会从该配置移除已存密码。

数据位于 EXE 旁的 data/profiles.json，导入的公共 CA 放在 data/certificates/。目录必须可写。复制到另一个 Windows 用户或系统后，加密密码和令牌可能无法解密，需要重新输入。损坏的配置文件不会被自动覆盖。

修改配置的服务器主机或端口会清除原账号、密码、令牌、分组和已记住的指纹。单独选择的证书文件和 CA 仍需按新服务器核对。同一用户的 UAC 提升可以使用其加密数据；用另一个管理员账号提升时属于另一用户。

## 配置与旧版迁移

**配置 → 导入配置** 支持 .bvpn 和兼容的 [VPN] INI 文件。公共 CA 可在高级配置中选择，或通过 CABase64 包含在配置中。CA 仅用于应用，不写入系统根证书库。

~~~ini
[VPN]
Name=公司 VPN
Server=https://vpn.example.com:4443/group
Protocol=anyconnect
PreferUDP=1
ReconnectSeconds=300
~~~

可选字段为 AuthGroup、ServerPin 或 CABase64。只接受完整公钥 SHA-256 指纹及可解析的公共证书，拒绝私钥、无效编码、无效 UDP/重连选项和非 HTTPS 地址。旧版 LockServer、客户端自定义 DNS/WFP/IPv6 开关不再控制新版，网络配置交给 OpenConnect 与网络脚本。

**配置 → 导出配置** 导出所选名称、地址、协议、分组、UDP、重连及指纹或公共 CA，不包含用户名、密码、令牌、私钥和本地脚本。服务端管理页生成的 .bvpn 也可导入。

0.4 及更早版本的数据和 Windows 凭据管理器记录不会自动迁移或删除。迁移时先在旧版导出 .bvpn，再到新版导入并重新登录。不要把旧 EXE 或 BridgeVPN.ini 混入新包。

## 托盘与系统兼容

设置菜单可选择最小化到通知区域、关闭时最小化、启动时最小化和单实例模式。默认关闭窗口先断开再退出；若启用关闭时最小化，请从 **退出** 完全结束程序。

x64 用于 64 位 Windows，x86 用于 32 位 Windows。完整保留同架构的 wintun.dll、vpnc-script-win.js 和 licenses/，无需预装 Qt、.NET 或编译器运行库。

Win7 SP1 是兼容目标，需要相应的 SHA-2 驱动签名和安全 DLL 加载系统更新。PE 审计不代替 Win7、真实 VPN 转发及睡眠重连验收，详见 [验证记录](VALIDATION.md)。
