# 客户端连接、证书与密码

## 直接连接

填写服务器地址、账号密码后点击连接。地址可以写成 `192.168.19.253:4443`，程序自动规范为 HTTPS。未连接时可随时编辑，旧配置的 LockServer 标志不再锁住输入框。

客户端先建立 TLS 并取得服务端证书，再处理登录表单。遇到未知自签证书或服务器名称不匹配时，弹窗显示服务器主机/端口、完整 `pin-sha256` 及可展开的证书详情。

核对后点击 **信息准确，记住并连接**（英文 **Accurate information**）。指纹会保存到当前 Windows 用户的应用目录，绑定 HTTPS 主机和端口；下次同一公钥自动通过。取消时不会发送密码，也不会保存指纹。

已记住的公钥发生变化时，显示新旧指纹，默认取消，必须选择 **确认更换并记住** 才能继续。管理员在配置中预先指定的固定指纹若不匹配则直接拒绝，避免覆盖事先分发的信任约束。过期、尚未生效、撤销或无效用途的证书不通过该确认流程。

这个实现参考 OpenConnect GUI 的证书回调和 OpenConnect 的 `openconnect_get_peer_cert_hash` / `openconnect_check_peer_cert_hash` 接口，保存完整公钥 SHA-256，不接受短指纹或 SHA-1。跨主机/端口重定向被拒绝。

## 配置导入与导出

“导入配置”支持 `.bvpn` 以及 PEM/DER 公共 CA。CA 仅在应用内使用，不写入 Windows 全局根证书库。简单的地址文件即可：

```ini
[VPN]
Server=https://192.168.19.253:4443
```

还可以选择附加 `CABase64=公共CA文件的Base64`，或 `ServerPin=完整pin-sha256指纹`；两者不能同时设置。导入拒绝私钥、过期 CA、非 HTTPS 地址和不完整指纹。导入后地址仍可编辑，改为另一台服务器时不沿用原 CA 或指纹。

使用 CA 验证时，服务器证书仍须包含对应 DNS 名称或 IP SAN。自签确认保存的是经用户明确认可的公钥，后续按该公钥固定验证。

未连接时点击 **导出配置**，选择 `.bvpn` 保存位置。文件包含输入框中的服务器地址、登录组、UDP/重连/DNS/IPv6 选项，以及该服务器已确认的完整指纹或导入的公共 CA。账号、密码、私钥、本机证书路径与诊断信息不会导出。

如果尚未保存证书信任，导出文件仍可使用；接收者首次连接时按正常流程确认证书。更换主机或端口后，导出不携带上一台服务器的 CA、指纹或登录组。通过可信渠道分发带指纹或 CA 的配置；导入的固定指纹不匹配时会直接拒绝连接。

服务端 **客户端配置** 页面也提供 `.bvpn` 下载：默认“首次连接时确认证书”，可改选“附带公共 CA 证书”；服务器地址可省略 `https://`。单独下载 CA 的入口继续保留。

## 保存账号密码

勾选“记住账号和密码”后，程序使用当前 Windows 用户的 Credential Manager。INI 中不存明文密码。凭据绑定服务器 URL 和信任信息；手动确认新的服务器指纹时，仅为这次明确确认的连接迁移已保存凭据。

更改服务器或账号会清除先前自动填入的密码。取消勾选删除当前连接的已存凭据；历史记录可在 Windows 凭据管理器中管理，名称以 `BulijieVPN/` 开头。

同一用户的 UAC 提升可读取已存凭据；通过另一个管理员账号启动时属于另一 Windows 用户。未记住密码时，提升后需重新输入，或先以管理员身份启动程序。

## 用户文件

文件位于 `%LOCALAPPDATA%\BridgeVPN`：

- `settings.ini`：语言、最近输入的服务器和记住选项。
- `connection.ini`：用户导入的基础配置。
- `ca-<hash>.pem`：导入的公共 CA。
- `trusted-<hash>.ini`：以规范化 HTTPS 主机/端口索引的已确认公钥指纹。

同目录的 `BridgeVPN.ini` 提供初始默认值，导入配置优先。改地址使用最近输入值，不会在点击连接时被旧配置改回。指纹文件无效时停止连接并显示错误，不自动忽略。

## 窗口与兼容性

空账号/密码先在本地提示；填写密码不等于已经发送密码。实际发送发生在证书验证/确认之后。连接过程中可以取消；成功后可断开。最小化进入托盘，关闭窗口会先清理 VPN 再退出。

x64 用于 64 位 Windows，x86 用于 32 位 Windows；必须保留匹配架构的官方 `wintun.dll`。Win7 SP1 为兼容目标，需要 SHA-2 和安全 DLL 加载系统更新，仍待实机验收。
