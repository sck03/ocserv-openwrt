# Lansyra 中文管理页

页面版本 **0.9.0-r1**，服务包 **ocserv 1.6.0-r6**，路径 **VPN → 岚序 Lansyra**，适用于 OpenWrt 25.12。当前使用管理接口 v3、设置契约 3 和隔离恢复记录 schema 4。服务包与管理页须成套全新安装，不迁移旧接口、旧设置或旧恢复记录。

## 安装与权限

套装包含 ocserv、luci-app-ocserv-easy 两个 APK。选择匹配架构，解压到新目录后运行 `sh install.sh`。重新部署前先使用原版本关闭 VPN 专用上网并完成恢复，再执行卸载和全新安装；说明见[卸载与重装](UNINSTALL.md)。

安装器初始化缺失证书，实际生成并预检运行配置，再配置受管防火墙。失败不会显示安装完成。管理页沿用 LuCI 登录，无预设账号密码；只读登录可以查询和下载公共材料，不能修改配置。普通网络设置需要 ocserv/firewall 写权限，隔离操作额外检查 dhcp 和支持代理的写权限。

仅支持本产品的 plain 账号认证和独立 VPN 地址池。启动渲染依赖原生 UCI，不自动更改 LAN/DHCP 或启用代理 ARP。错误码及必要代码位置写入日志，日志不包含密码、配置正文或原始异常内容。实机检查见[路由器验收](ROUTER-TESTING.md)。

## 账号与在线用户

可以添加账号、修改用户名/密码/组、停用、恢复、删除账号及断开单条连接。新密码至少 8 个字节，需要再次确认；修改时留空保留原密码。密码以 SHA-512 crypt 哈希保存，不回显哈希。无效记录显示“需重设密码”。不需要用户组时保留 `*`。

保存同时更新永久配置及服务读取的密码文件。修改密码、账号或组以及停用账号会撤销该账号的旧会话，普通账号变更不重启其他连接。无法确认撤销结果时回滚配置和密码文件。

账号状态与在线状态分开显示。在线按区分大小写的完整登录名称匹配，多条连接显示数量。查询失败显示未知，移除旧连接操作；成功取得空列表才显示离线。

两张表每页 50 条。搜索、页码及有效操作焦点在刷新时保留，只重建变化的可见行；窄屏表格局部滚动。重复点击当前标签不会清空未保存输入，标签支持左右方向键及 Home/End。

## 状态刷新与并发

页面每 3 秒读取 `status` 摘要，包括服务状态、在线数量、在线代次及恢复状态。只有账号页可见且代次变化时才请求 `online` 完整列表。初次加载和明确的完整刷新包含初始记录。

在线列表与小摘要共用 5 秒有效期。摘要命中不读取/解码完整在线 JSON、不执行 occtl、不写缓存。独立查询锁合并同时发生的刷新，最多等待 5 秒；配置事务不使用这个查询锁。缓存损坏或不可写时回退有界的实时查询。

隐藏页面、切换列表标签、打开编辑弹窗或提交时取消被取代的读取。旧读取的成功、失败和收尾都不能覆盖新请求；列表也不能把已更新的摘要退回旧代次。普通读取连同响应体最多等待 15 秒，修改最多等待 120 秒。修改超时会提示核实结果，不自动重发。

未保存表单始终保留其原配置修订号。后台隔离状态变化可以更新摘要，完整刷新和自动确认等到表单结束后再执行；其他页面修改过配置时，保存会报冲突。

## 服务设置与 DNS

可设置 TCP/UDP 端口、IPv4/IPv6 地址池、DNS、全量或网段分流路由、在线限制、断线检测、证书路径及员工连接地址。应用前预检配置，运行中的网络参数变更需要确认重启。

本版统一下发隧道 DNS，不再提供客户端按域名选择解析器的 DNS 分流开关。使用 OpenClash、Nikki 或 Momo 时，由代理端的 DNS 和分流规则处理后续请求。流量的“全部通过 VPN / 仅指定网段”仍然独立可选。

DNS 必须是 1–3 项连续 IP 列表；只有 IPv4 地址池时至少需要一个 IPv4 DNS。公开入口为 IP 时，不能与 DNS 使用相同地址。默认 DNS 为 1.1.1.1，仍需核对实际可达性；VPN 专用上网会改用 VPN 网关 DNS 并配置代理接入。

分流路由最多 128 项，非法项使整次保存失败，等价写法去重但保留不同前缀。请求拒绝 JSON null、未知设置字段和已删除的 `split_dns`。自定义 `ocserv.conf.local` 不能覆盖 `split-dns` 或 `tunnel-all-dns`；其他受管字段冲突也会拒绝保存。

仅修改员工连接地址会立即更新导出信息，不重启 VPN；相同配置不触发无效写入或重启。在系统维护中可以确认重启服务，重启会断开活动连接。

## 客户端配置和证书

先选择 Windows、Android、macOS、iOS 或 Linux，再选择该平台支持的信任方式。默认导出固定公钥 Pin；Apple 仅接受 Pin，Linux 使用 CA/首次确认。公共文件为版本 1 `.vpn`，不包含账号、密码、令牌、私钥或本机脚本。能力矩阵见[公共配置契约](CONNECTION-PROFILE.md)。

固定 Pin 从实际服务端证书提取，公钥更换后需要重新分发。首次确认模式由客户端核对证书。CA 模式在保存及下载时验证实际证书链和连接地址；切换外部证书后，不会继续分发不匹配的初始 CA。验证过程中材料变化也会拒绝导出。单独下载 ca.pem 同样需要与当前证书链匹配。

CA 不可用时显示原因并禁用相应保存、下载按钮，可以明确改选其他支持的方式。多证书或虚拟主机不能被猜测为单一 Pin/CA。证书缺失时提供生成入口，已有外部证书不会被覆盖；过期证书需要管理员续期。

## VPN 专用上网和诊断

该功能默认关闭，仅支持经过确认的 N1 单网口旁路由拓扑。启用前须运行 ocserv，并安装、配置、运行 OpenClash、Nikki、Momo 中的一款；多款同时启用会报冲突。

开启时配置 VPN 入口、DNS、访问控制及隔离规则；普通 LAN 设备不能借 N1 的网关、DNS 或代理端口上网。关闭时恢复本功能改动，保留后续新增账号、订阅和其他无关修改。应用后页面必须重新访问成功才确认，否则超时尝试恢复。升级 Nikki/Momo 或切换代理前先关闭本功能，详见[专用上网说明](VPN-ONLY-PROXY.md)。

不开启隔离也可以使用代理。Nikki/Momo 的服务事件会接入动态 VPN 接口及 DNS，保持普通 LAN 设置；配置一致时不重复写入或重启。

“检查代理”按需读取运行状态，不增加常驻轮询：

- 三种代理都检查实际 DNS 规则目标和 TCP/UDP 监听。
- Nikki/Momo 额外检查 VPN 接口集合、Redirect/TPROXY 端口及 TUN 路由/策略。
- OpenClash 没有同样的接口集合，VPN 入口显示未知，不用进程存在替代接入证据。

监听存在不证明节点或外网可用，仍需从 VPN 客户端实测 DNS 和网页访问。

## 故障恢复和维护

普通事务、隔离事务在恢复前校验完整记录和当前文件，拒绝用旧快照覆盖后续修改。损坏或版本不符时保留现场；恢复记录属于运行安全机制，不能当作缓存删除。升级前须用原版本完成恢复。

在线最多 4096 条，撤销核实最多 65536 条；单条 64 KiB、嵌套 32 层、总响应 64 MiB，并受命令时限约束。只保留界面消费的在线字段，任何解析失败都不会发布部分成功结果。

系统维护页提供可复制的卸载命令与步骤；实际卸载通过局域网 SSH 进行。工具在删除软件包期间保留 Lua/nixio，完成恢复和清理后释放。备份位于 `/root/lansyra-before-uninstall-*`。版本构建与真实设备边界见[验证记录](VALIDATION.md)。
