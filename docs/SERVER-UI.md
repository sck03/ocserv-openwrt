# Lansyra 中文管理页

页面版本：**0.6.3-r1**。路径：**VPN → 岚序 Lansyra**。基于 LuCI 登录和权限检查，适用于 ocserv 1.6.0 及后续版本、OpenWrt 25.12。

在线状态轮询共用最多 5 秒的运行期快照；手动刷新及完成操作后会读取实时在线列表。版本和能力检测按可执行文件身份短时复用，配置修改仍现场校验版本。缓存损坏或不可写不会影响实时查询和配置恢复。

## 安装

本次 APK 套装仅包含 `ocserv` 和 `luci-app-ocserv-easy`。选择与设备匹配的架构，完整上传到新目录后运行 `sh install.sh`，再重新登录 LuCI。同名 Lansyra 安装会原地升级并保留配置；安装成功后会移除原 `luci-app-ocserv` 和其中文翻译，避免重复页面。通用安装见 [OpenWrt 多架构说明](OPENWRT.md)，N1 的证书和 TUN 说明见 [N1 安装指南](OPENWRT-N1.md)。

包直接依赖 `ocserv`，以及 `luci-compat`、`luci-lib-nixio`、`luci-lib-jsonc`、`libuci-lua`，由当前固件的软件源解析。没有默认管理账号，沿用 LuCI 自身的登录。

## 账号与在线用户

添加账号、改密码、改用户名/组、停用、恢复、删除和断开当前连接。新增密码至少 8 个字符，并需再次输入确认；点击 **保存并生效** 后同时更新永久配置和服务读取的密码文件，不必再找另一处“保存并应用”。修改正常账号时，两处密码留空可保留原记录。页面从不回显密码哈希；不需要分组时可保持默认 `*`。

密码以 SHA-512 crypt 哈希保存。无效记录会禁止登录并标为“需重设密码”；为该账号设置新密码即可恢复，其他账号继续可用。本版采用全新安装，已移除旧密码自动迁移入口。

改密码、改账号/组或停用时，使用 ocserv 的会话撤销功能让该账号旧登录失效。普通账号变更不重启其他用户的 VPN。网络参数变更会在检查配置后重启服务。

## 服务设置

端口、地址池、DNS、全量/分流路由、UDP、每账号在线数、断线检测和连接配置中的公开地址。底部提供 **保存并应用**；应用前检查配置，成功后重新读取实际保存值。每账号上限为 1 时，由服务端限制同时在线设备数；断网席位需等待检测释放。

仅修改“员工连接地址”时立即更新导出信息，不重启 VPN，也不改写账号、DNS 和路由。重复保存相同设置不会写入配置或重启服务；实际网络参数变更仍需确认并通过配置检查。

全新安装先添加账号、确认地址池不与 LAN 重叠，再启动服务。证书可通过安装脚本或 `/etc/init.d/ocserv initcerts` 生成。临时配置 `/var/etc/ocserv.conf` 和 `/var/etc/ocpasswd` 由启动脚本生成，不应手动修改。

## VPN 专用上网

不开启本开关时，VPN 仍可使用代理。0.6.3 使用 OpenWrt 25.12 实际发送的内部服务事件，在启动、重启后自动接入动态 VPN 接口及 DNS，并在管理服务升级后补做接入。保留普通 LAN 的接口、访问控制、订阅和分流规则；配置一致时不重写暂存文件或重启代理。需要代理处于完整代理模式，TCP 为 redirect/tproxy/tun，UDP 为 tproxy/tun。需要所有网页经过 VPN 时，在服务设置选择“全部流量通过 VPN”；分流路由仍按原设置工作。

**检查代理** 只在点击时读取运行状态：VPN 入口、DNS/Redirect/TPROXY 目标端口及其 TCP/UDP 监听、TUN 路由表和策略规则。缺失入口时会明确提示；“联动代理”只表示检测到代理进程。监听存在仍需结合实际 DNS 和网页访问确认节点可用。

可选开关默认关闭。支持已确认的 N1 单网口旁路由拓扑；“开启”自动配置相关网络访问，“关闭并恢复”还原本功能改动。启用前需要 OpenClash、Nikki、Momo 中的一款已配置并开启，以及 ocserv 已运行。页面显示自动识别的代理；多款同时启用会提示冲突。

管理电脑地址由当前 LuCI 连接读取。页面在应用后重新访问成功才确认；连接失败时后台等待超时并尝试恢复。不会覆盖代理的订阅、节点和分流规则。升级 Nikki/Momo 或切换代理前先关闭本开关。详细边界与故障恢复见 [开关说明](VPN-ONLY-PROXY.md)。

该操作额外要求 firewall、dhcp、openclash、nikki 和 momo 的 UCI 写权限，随本页管理 ACL 提供；普通只读登录不能修改。开启期间网络设置按钮暂时禁用，账号管理继续可用。

## 客户端配置

填写客户端实际连接的地址，例如 `vpn.example.com:4443`、`[IPv6地址]:4443` 或 `192.168.19.254:4443`，选择证书验证方式后点击“保存客户端设置”，刷新后仍会保留地址和选择。保存立即生效，不重启 VPN，开启专用上网时也可保存。点击“下载 .vpn 连接配置”使用当前选择，导入客户端后才决定该客户端如何验证服务器。默认“固定服务器指纹”，从当前服务端证书提取公钥指纹；更换公钥后需重新分发。也可选择“首次连接时确认证书”，或“附带公共 CA 证书”，后者要求服务器证书覆盖填写的域名或 IP。公共 `ca.pem` 仍可单独下载。外网条件、CGNAT 和 IPv6 接入见[公网连接说明](WAN.md)。

局域网同样需要服务端 TLS 证书，无需域名。安装和首次启动都会自动生成缺失的本地证书；如果证书尚未就绪，本页显示原因，并提供“生成缺失证书”。已有证书和外部证书不会被自动替换。若出现“安装尚未完成”，需重新运行完整套装的安装脚本以完成 VPN 网络设置。

员工导入后填写各自的账号密码，也可直接填写地址连接。Windows 客户端的“导出配置”可进一步分发已确认的指纹及连接选项。所有导出都不包含账号密码、CA 私钥或服务端私钥。

## 并发与恢复

账号及服务操作检查配置修订和 UCI 待提交变更。管理页、后台恢复、安装器及套装中的命令行账号脚本通过公共租约模块使用同一把 POSIX 文件锁；并发操作会提示忙碌，进程退出自动释放锁。失败时尽量回滚本次改动；不会把其他页面稍后提交的配置直接覆盖成旧快照。普通管理操作备份位于 `/etc/ocserv/easy-backup`，专用上网备份位于 `/etc/ocserv/easy-guard`，均应只由 root 访问。

普通配置事务使用原生 `uci` 绑定，在 `/var/run/ocserv-easy/config-stage` 的独立目录生成候选；LuCI 的 rpcd UCI 接口不支持自定义目录，不能用于候选提交。各文件最多 256 KiB；超限在正式替换前拒绝。替换前把原文件、候选和事务状态写入 `/etc/ocserv/easy-transaction`。请求进程中断后，下次修改、后台检查或开机恢复会核对现场并恢复未完成事务；检测到管理员的后续修改则保留现场和记录，提示处理。恢复服务失败时保留可重试记录。完成后清除事务状态、过期恢复副本及 RAM 中的临时配置，固定备份不会随运行时间增加。

公共存储模块在文件同步、原子重命名后继续同步父目录，事务完成时也同步恢复标记的删除；专用上网事务复用同一套写入流程。这改善断电时配置文件与恢复记录的顺序保证，最终持久性仍依赖固件文件系统和存储设备正确实现同步写入。

页面保存会使更早发出的完整刷新请求失效。较晚返回的旧响应不能覆盖成功保存后的账号列表或设置。

服务设置同时要求 ocserv、firewall 写权限，并拒绝两个包中尚未应用的 UCI 修改。修改端口或地址池时也保留防火墙备份。修复防火墙漂移的同时会保存本次提交的员工连接地址，不丢弃地址修改。

服务设置保存时会同时校验并同步项目维护的 VPN 防火墙段：VPN 地址池更新 NAT 源网段，TCP/UDP 端口更新入口规则。防火墙检查或重载失败时，ocserv 配置和防火墙配置一起恢复；自定义同名段会被拒绝，避免出现“页面已保存但 VPN 无法转发”的状态。

项目维护的四个命名规则段会完整同步，包括移除使规则失效的禁用项和额外选择条件；其他命名的管理员规则保留。在线状态没有变化时保留现有界面节点，减少持续轮询产生的重绘。
