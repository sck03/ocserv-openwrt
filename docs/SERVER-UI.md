# 中文服务端管理页

安装 `luci-app-ocserv-easy` 后，进入 **VPN → OpenConnect VPN → 布利杰VPN**。页面随 LuCI 的语言选择显示简体中文或 English。原来的“服务设置”“用户设置”“CA 证书”保留。

需要 **ocserv 1.5.0 或更新版本**。如果仍是 1.3.0，页面会显示升级提示并禁用修改操作；先按 [N1 升级步骤](OPENWRT-N1.md)升级服务。底层沿用原 OpenWrt UCI 配置与 procd 服务，不另建账号数据库。

## 日常操作

- **账号**：添加登录账号；修改时密码留空表示保留原密码；停用后可恢复原密码；也可删除账号。
- **即时失效**：修改密码、账号名、用户组，停用或删除时，通过 1.5.0 的 `occtl terminate user` 清理该账号当前与缓存会话。其他账号无需重连。
- **在线连接**：查看用户名、来源 IP、VPN IP、连接时间，单独断开连接。只断开允许再次登录；要阻止登录请停用账号。
- **常用设置**：端口、最大连接数、每账号连接数、地址池、DNS、全部或指定网段路由。更多设置包含 UDP、压缩、IPv6、默认域名和员工连接地址。
- **客户端下载配置**：下载包含地址与公共 CA 的 `.bvpn`，或单独下载 `ca.pem`。导出文件不含账号密码、哈希或私钥。
- **服务**：启动、停止、重启及开机启动。

密码使用随机盐的 SHA-512 crypt 保存，不返回浏览器。变更前检查已有配置和并发修改；网络设置先由 ocserv 校验，再保存并应用。服务运行时，改网络设置会要求确认短暂重启。失败会尝试恢复先前配置；最近一次变更备份位于仅 root 可访问的 `/etc/ocserv/easy-backup`。

该页针对普通账号密码认证。使用 PAM、自定义密码文件、代理 ARP 或与页面冲突的额外配置时，页面会明确报错，需在原服务设置页或对应配置中管理。

## 安装包

GitHub Actions 的两个服务端 artifact 均包含：

1. `ocserv` 1.5.0；
2. 原版 `luci-app-ocserv`；
3. `luci-i18n-ocserv-zh-cn`；
4. 新版 `luci-app-ocserv-easy`。

24.10 使用 IPK/opkg，25.12 使用 APK/apk。安装普通依赖时使用与固件匹配的软件源。页面依赖 `luci-compat`、`luci-lib-nixio`、`luci-lib-jsonc`；包管理器会解析依赖。安装后重新登录 LuCI；若菜单没有刷新，可重启路由器的 uhttpd 服务。

防火墙、端口映射、DNS 服务监听与 OpenClash 规则仍由对应管理页控制；本页修改 ocserv 不会自动建立这些规则。
